Drafting instrument

The engineer's light table: deep blueprint surfaces, hairline rules, and monospace-forward labels treat the architecture like a precision drawing under instrument light. Amber and cyan act strictly as indicator lights — amber for attention, cyan for signal — so state reads at a glance without decoration. Chrome is squared and exact; the canvas keeps Excalidraw's hand, so the drawing itself still feels authored rather than generated.

What changes under simulation

  • Packets ride the wires as points of light. The drawing itself never moves — only the signal does, the way a logic analyzer overlays a schematic.
  • Throughput readouts sit beside each wire as instrument chips — 142 req/s — measured values in monospace, not a dashboard.
  • A compact transport bar — play, pause, step, 1x, 00:12 — keeps control quiet and bottom-center, and the amber lamp in the view switcher marks the live state.
